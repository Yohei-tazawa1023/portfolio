業務システム開発 ／ 個人開発

案件情報管理サイト

案件メールを貼り付けるだけで、AI が案件名・単価・スキルなどに整理して保存。検索・並び替え・Excel/CSV 出力・削除まで行える管理サイトです。

※ 画像はすべて架空のデータです。

制作期間
約 4 日（2026年10月）
担当
企画・設計・開発・テスト（個人開発）
使用技術
PHP 8.2 ／ Laravel 12 ／ MySQL ／ HTML・CSS・JavaScript ／ Gemini API（Claude API への切替にも対応）／ PHPUnit ／ Git
公開
個人利用のため非公開（ローカル環境で動作）

制作背景

エンジニア向けの案件メールは、書き方が会社ごとに違い、単価・必須スキル・稼働形態などの条件を見比べるのに手間がかかります。メール本文を貼り付けるだけで項目ごとに整理され、一覧で検索・比較でき、スプレッドシートにも出力できれば、案件の確認と管理が楽になると考えて制作しました。

制作過程

  1. 要件の整理と段階的な計画「登録 → 一覧・検索 → 出力」の順にフェーズを分け、各段階で仕様どおりに動くかを確認してから次へ進める進め方にしました。
  2. データベース設計案件テーブルを設計。単価は「原文の表記」と「並び替え用の数値（月額・円）」の両方を保存し、表記の揺れがあっても並び替えや絞り込みができるようにしました。
  3. AI との連携メール本文を AI に渡し、決まった形式（JSON）で項目を受け取る構成にしました。1 通に複数の案件があれば 1 件ずつに分割。無料枠の Gemini で検証し、設定で Claude にも切り替えられる作りにしています。
  4. 一覧・検索・並び替え・絞り込み複数キーワード、稼働形態、単価の範囲、並び順、ページ移動を実装しました。
  5. Excel/CSV 出力一覧の条件をそのまま反映して出力。Excel は列幅・折り返し・見出しの固定つきで、スプレッドシートでも読みやすくしました。
  6. 削除機能確認画面つきで、複数件まとめて取り消せるようにしました。
  7. テストと動作確認自動テスト（200 件超）と、画面・実際のデータベースでの動作確認を重ねました。ダブルクリックで起動できるランチャーも作成しています。

意識したこと

  • AI の答えを鵜呑みにしない。単価の換算結果はサーバー側でも検証し（範囲外は空にする）、案件数に上限を設け、AI が失敗したときは何も保存しません。元のメール本文も保存し、あとから確認できます。
  • 安全性。メール本文の中に書かれた指示には AI が従わない設計にし、SQL インジェクション・XSS・CSRF への対策を行いました。Excel/CSV に出力するときは、数式として実行されてしまう値（= や + で始まる文字列）への対策もしています。
  • 使いやすさ。日本語の分かりやすいエラー表示、確認画面つきの削除、スマホ対応、Excel で読みやすい列幅にこだわりました。
  • 個人情報への配慮。案件メールには取引先の情報が含まれるため、無料枠の AI は入力内容が学習に使われる可能性があることを踏まえ、公開用のスクリーンショットには架空のデータだけを使っています。
  • 壊れにくさ。段階ごとのレビューと自動テストで、機能を追加しても既存の機能が壊れないようにしました。

開発には AI アシスタント（Claude Code）を活用しました。要件の決定・仕様の判断・動作の確認は自分で行い、AI の提案をそのまま使うのではなく、検証と修正を重ねています。

Webサイト制作

サラダ会議

「新鮮なつながりを、ひとつのサラダから」をコンセプトにした、架空企業のコーポレートサイトです。JavaScript で、スクロールに合わせた動きを加えました。

制作期間
約 1 週間
担当
構成・デザイン・コーディング
使用技術
HTML ／ CSS ／ JavaScript（ライブラリなし）／ Google Fonts（Poppins・Noto Sans JP・Dancing Script）

制作背景

食を通じた「人のつながり」をテーマに架空の企業を設定し、企業サイトの基本構成（コンセプト・サービス・会社概要）を、見やすさを重視して制作する練習として作りました。

制作過程

  1. コンセプトの設定企業の理念とターゲットを決め、キャッチコピーを考えました。
  2. 構成の設計Concept ／ Service ／ Company の 3 つに絞り、伝えたい順に並べました。
  3. 配色・フォントの選定緑を基調に、英字と日本語の書体を組み合わせました。
  4. コーディングHTML と CSS（Flexbox）で実装しました。
  5. スマホ表示の調整画面幅が変わっても読みやすいように調整しました。
  6. 動きの追加JavaScript で、見出し・文章・写真がスクロールに合わせて順に現れる動き、ヒーロー画像の視差、読み進めバー、トップへ戻るボタンを加えました。

意識したこと

  • 第一印象。ファーストビューに、世界観が伝わる写真とキャッチコピーを大きく配置しました。
  • 清潔感。緑を基調に、余白を広めにとって読みやすくしました。
  • 情報の整理。サービスを 3 つに分けて、短い文章で読み進められるようにしました。
  • どの画面でも読める。スマートフォンでも崩れないレイアウトにしました。
  • 動きは控えめに、内容が先。JavaScript が動かないときや、端末の「動きを減らす」設定のときでも、内容がそのまま読めるようにしました。

Webサイト制作

Salon Sample

「髪と心を癒すサロン」を想定した美容室のサンプルサイトです。メニュー・スタイル・スタッフ・アクセス・予約までを 1 ページにまとめ、スマートフォンでもレイアウトが崩れないように調整しました。

制作期間
約 1 週間
担当
構成・デザイン・コーディング
使用技術
HTML ／ CSS ／ JavaScript ／ Google Fonts（Noto Serif JP）／ Google マップ埋め込み

制作背景

店舗サイトの定番の構成（メニュー・スタイル・スタッフ・アクセス・予約）を、ひと通り作ってみる練習として制作しました。予約フォームや地図など、実際のお店のサイトで必要になる要素も入れています。

制作過程

  1. 構成の設計来店につながる順番（コンセプト → メニュー → スタイル → スタッフ → アクセス → 予約）で構成しました。
  2. デザイン落ち着いた色と明朝体で、上質な雰囲気にしました。
  3. コーディングHTML と CSS で実装し、メニュー表や予約フォームを作りました。
  4. 動きの追加JavaScript で、スクロールに合わせてふわっと表示される動きをつけました。
  5. スマホ表示の調整スマートフォンでメニューが縦に折れ曲がったり、横にはみ出したりしないよう、ハンバーガーメニューや画像・フォームのサイズを見直しました。パソコン表示の見た目は変えていません。

意識したこと

  • スマホでの使いやすさ。幅 320px の小さな画面まで確認し、メニューやボタンを押しやすい大きさにしました。入力欄は iPhone で拡大されない文字サイズにしています。
  • 予約までの導線。ヘッダー、ファーストビューのボタン、ページ下部のフォームと、どこからでも予約へ進めるようにしました。
  • 上質な雰囲気。明朝体と余白で、落ち着いた印象に仕上げました。
  • 見やすい料金表。メニューと料金を、ひと目で比べられるように並べました。
  • 使いやすいフォーム。氏名・電話・メール・日付・メニュー・メッセージを、迷わず入力できる並びにしました。

バナー制作

SAMURAI ENGINEER バナー

Web デザインスクールの無料説明会への誘導を想定した、正方形（1080×1080）の広告バナーです。

制作期間
約 1〜2 日
サイズ
1080 × 1080 px
使用ツール
Canva ／ Figma

制作背景

学習サービスの無料説明会へ誘導する広告を想定して、「伝えたいことを一瞬で伝える」バナーの練習として制作しました。

制作過程

  1. 訴求の整理誰に何を伝えるか、最も伝えたいメッセージを決めました。
  2. 情報の優先順位づけメッセージ → 特典 → 行動の呼びかけの順に、大きさを変えて配置しました。
  3. 配色・レイアウト青と黄色を使い、人物写真と文字が重なっても読めるように調整しました。
  4. 仕上げ文字の大きさ・余白を見直し、小さく表示されても読めるか確認しました。

意識したこと

  • 一番伝えたいことを最大に。「稼げるスキル」を最も大きく見せました。
  • 特典を目立たせる。「受講料 1ヶ月 0 円」を円形のバッジで強調しました。
  • 行動を促す。下部の帯とボタン風の矢印で、「オンライン説明会へ」の次の行動を示しました。
  • 色のコントラスト。信頼感のある青に、注目を集める黄色を合わせました。

バナー制作

OUTDOOR FESTIVAL 2024 バナー

アウトドアイベントの告知を想定した、横長のバナーです。日時・場所・「入場無料」を一目で伝える構成にしました。

制作期間
約 1〜2 日
サイズ
1200 × 628 px
使用ツール
Canva ／ Figma

制作背景

屋外イベントの告知を想定して、SNS やウェブ広告で目に留まりやすい横長バナーの練習として制作しました。

制作過程

  1. 伝える情報の整理イベント名・日付・場所・入場無料、の 4 つを必須の情報としました。
  2. 写真の選定家族連れ・テント・夜のキャンプなど、楽しさと雰囲気が伝わる写真を組み合わせました。
  3. レイアウト緑の面に情報をまとめ、写真が周りを囲む構成にしました。
  4. 仕上げ文字の大きさ・余白を調整しました。

意識したこと

  • 情報の階層。イベント名を最も大きく、日付は白い帯で、場所は下に、と順に目が動くようにしました。
  • 世界観。緑の面と、ロゴ風の手書き文字で、アウトドアらしい雰囲気を出しました。
  • 参加のしやすさ。「ENTRANCE FREE」のバッジで、気軽に来られることを伝えました。
